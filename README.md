## About Me

<p align="left">
I am a final-year B.Tech student specialising in Artificial Intelligence and Machine Learning at the University of Engineering and Management, Kolkata. My engineering focus spans the full spectrum from classical ML pipelines to production-grade Generative AI applications — with a strong bias toward shipping real, working systems rather than just experiments.

I build end-to-end AI-powered products that integrate large language models, computer vision, and statistical ML into web interfaces and command-line tools. My stack is Python-first for model and backend work, with clean vanilla JS/HTML frontends for rapid deployment. I treat every project as a product: structured, maintainable, and built to be understood by anyone who clones the repository.

Beyond models, I actively develop my understanding of MLOps concerns — particularly data drift detection and model observability — which I believe is the gap between a prototype and a trustworthy production system.
</p>

**Open To:** SDE Internships · AI/ML Internships · GenAI Application Development Roles · Research Collaborations · Open Source Contributions

<details>
<summary><strong>ML Drift Monitoring System</strong> — MLOps · Statistical Testing · Python · Visualisation</summary>

<br/>

An end-to-end MLOps pipeline for detecting and visualising data drift in production ML systems. The project simulates realistic distribution shifts across a synthetic dataset, applies sliding-window monitoring, and computes feature-wise statistical metrics to flag model degradation before it impacts prediction quality.

<div align="center">

| Attribute | Details |
|---|---|
| Stack | Python, scikit-learn, SciPy, pandas, Matplotlib, Seaborn |
| Scale | Synthetic multi-feature dataset; Logistic Regression baseline on Iris-derived schema |
| Performance | KS Test and PSI computed per window per feature; drift alerts thresholded at p < 0.05 |
| Security | Fully offline; no external API dependencies |
| Impact | Demonstrates production-grade MLOps observability patterns |
| Repository | [Mehul-8/ml-drift-monitoring](https://github.com/Mehul-8/ml-drift-monitoring) |

</div>

The pipeline covers synthetic data generation with configurable drift injection, sliding-window segmentation, Kolmogorov–Smirnov Test and Population Stability Index per feature, time-series drift trend visualisation, and feature importance bar charts. Designed as a portfolio-grade demonstration of MLOps discipline and statistical rigor.

<br/>
</details>
